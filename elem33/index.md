# Elemental 33 (Beta)

[Open The Game](https://elem33.viktigsau.net)

## How To Play

*Note: it's recomended to be 3+ players*

* **Create a game:** click the create a game button
* **Share the game code:** copy the game code and send it to the other players so they can join
* **Combine elements:** Combine elements by clicking on one and then clicking on another element
* **Create a recipie:** If the recipie you created doesn't exist you will see a popup. click the popup to see the recipie creator. set the name and color and click submit.
* **Wait for the recipie to get voted on:** When your recipie meets the voting threshold or the voting time limit it will get accepted and all users will be able to make this recipie
* **Get Score:** The first player to vote on a recipie (the creator) will get 100 points, the last person will get 50 points, intermidiate players get a score inbetween 100 and 0 based on a secound degree polynomial

## Settings

* **Voting Threshold:** the percent of players needed to vote before a recipie gets accepted
* **Voting Time Threshold:** the time in secounds before a recipie gets automaticly accepted
